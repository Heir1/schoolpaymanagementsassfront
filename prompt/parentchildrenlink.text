## Système de Liaison Parent-Enfant
Création d'une interface frontend pour permettre aux parents de lier/délier leurs enfants à leur compte, avec un flux en 4 étapes : recherche d'école → sélection de classe → sélection d'élève → gestion des liens.

## 🎯 Objectif
Développer une interface intuitive, responsive et user-friendly pour le processus complet de liaison parent-enfant.

## 📊 API Endpoints & Réponses

### 1. **Recherche Écoles** (Autocomplétion)
```
GET /api/v1/parent/schools/search?search=terme
```
**Réponse :**

### 5. **Lier un Enfant**
```
POST /api/v1/parent/children/link
Body: { "student_id": 1 }
```
**Réponse :**
```json
{
    "status": "success",
    "message": "Enfant lié à votre compte avec succès",
    "data": {
        "link": {
            "student": { ... },
            "is_primary": true,
            "linked_at": "2026-02-09T15:56:03.489633Z"
```

```json
}
```

## 🎨 UX/UI Requirements

### **Flux Principal (Wizard en 4 étapes)**

#### **Étape 1 : Recherche École**
- 🔍 Champ recherche avec autocomplétion en temps réel
- ⏳ Debounce 300ms pour éviter trop de requêtes
- 📱 Design mobile-first avec suggestions sous le champ
- 🏫 Carte résultat : logo + nom + type + adresse + bouton "Sélectionner"
- 📍 Indicateur "Aucune école trouvée" / "1 école trouvée"

#### **Étape 2 : Sélection Classe**
- 🏫 En-tête avec nom de l'école sélectionnée
- 📊 Groupement par niveau (accordéon/onglets)
- 🗓️ Pour chaque classe : nom + année scolaire + nombre d'élèves
- 🎯 Badge "Actif" si l'année scolaire est en cours
- 🔄 Bouton "Voir les élèves" avec feedback visuel

#### **Étape 3 : Sélection Étudiant**
- 📚 En-tête avec [École > Classe] (breadcrumb)
- 👨‍🎓 Tableau/liste d'élèves avec :
  - Avatar/initiale
  - Nom complet + code étudiant
  - Âge + date de naissance
  - Badge "Déjà lié" (grisé) / "Disponible" (vert)
- ✅ Checkbox ou bouton "Sélectionner" par élève
- 📝 Option "Vérifier" avant liaison (modal de confirmation)

#### **Étape 4 : Confirmation & Résultat**
- 👤 Card récapitulative de l'élève
- 📝 Message personnalisé selon statut :
  - "Nouvelle liaison"
  - "Restauration de liaison précédente"
  - "Déjà lié" (erreur)
- 🎯 Option "Définir comme parent principal" (checkbox)
- 🎉 Animation de succès après liaison
- 🔗 Bouton "Voir mes enfants" / "Lier un autre enfant"

### **Dashboard Parent**

#### **Section "Mes Enfants"**
- 📊 Statistiques en haut : total/principal/secondaire
- 🎯 Filtres : Tous / Principaux / Secondaires
- 👥 Liste avec :
  - Photo élève / avatar avec initiales
  - Nom + classe + école
  - Badge "Parent principal" (étoile/or)
  - Date de liaison ("Il y a 2 jours")
  - Menu d'actions (⋮) : Délier / Rendre principal
- 🗑️ Modal de confirmation pour déliage
- 📱 Design card sur mobile, tableau sur desktop

#### **Section "Statistiques"**
- 📈 Graphique circulaire : Répartition par école
- 📊 Graphique à barres : Répartition par niveau
- 📋 Tableau : Distribution par classe
- 📅 Section "Activité récente" : 5 dernières liaisons
- 🎂 Section "Âges" : moyenne/min/max
- 💾 Option d'export (PDF/Excel) si pertinent
