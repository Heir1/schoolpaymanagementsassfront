```
POST /api/v1/auth/login
```

```json
{

  "password": "j18d1m*01"
}
```

## 🧠 Frontend Requirements

Please implement:

### ✅ Authentication Logic

* Login form
* Store token securely (HTTP header: `Authorization: Bearer <token>`)
* Logout handling
* Auto-fetch authenticated user (`/auth/me`)

### ✅ Role-Based Access Control

* `superadmin`
* `school_admin`
* `parent`

Each role must see **only its authorized pages and actions**.

### ✅ Protected Routes

* Block unauthenticated access
* Redirect based on role
* Handle expired or invalid tokens gracefully

### ✅ UX & UI

* Institutional, calm, and professional design
* Clear error messages
* Loading states during auth requests
* No fintech-aggressive animations
